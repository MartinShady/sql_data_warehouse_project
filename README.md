# SQL Data Warehouse Project

## About the Project

This project is a SQL Data Warehouse built using SQL Server.

I built this project after completing Baraa's Data Warehouse course to practice and improve my SQL and Data Engineering skills.

The project focuses on building a modern Data Warehouse, including ETL processes, data modeling, and analytics.

It integrates data from two sources (CRM and ERP) and organizes it into different layers to prepare the data for analysis.

## Project Architecture

The project follows the Medallion Architecture::
<img width="3090" height="1830" alt="image" src="https://github.com/user-attachments/assets/550b2290-5605-4879-a23c-19ff5e763b16" />
- **Bronze Layer:** Stores raw data from source files.
- **Silver Layer:** Cleans and transforms the data.
- **Gold Layer:** Organizes the data into business-ready tables.
